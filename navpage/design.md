# 猫猫王国 · 导航页设计文档

> 个人网关统一入口页。本文件是导航页的**设计规范唯一权威来源**，改动视觉/结构先改这里。
> 通过"搜集优秀项目 → 挖掘设计喜好 → 落地文档"循环迭代。

## 1. 定位

- **是什么**：个人门户（主入口），挂到 `maomaokingdom.top`
- **给谁用**：分两类受众
  - **访客**（任何人）：看公开内容（博客、文档、简历）
  - **自己/授权的人**：进入私有服务（LiteLLM 网关、消耗统计等，需登录）
- **做什么**：一张页同时承载"对外展示"和"对内服务"，公开与私有一体

## 2. 设计方向（一句话）

**浅色底 + 瑞士排版 + 玻璃拟态**：大量留白、克制低饱和配色，用毛玻璃的半透明层次补足质感，避免扁平。

## 3. 设计原则

1. **玻璃拟态质感**：卡片用半透明 + 背景模糊（backdrop-filter）体现通透的层次，而非纯色平涂
2. **瑞士排版**：干净的字距、字重、字号层级，理性精致
3. **大量留白**：呼吸感强，元素不拥挤
4. **平静低饱和配色**：浅色为主，不刺眼，单强调色点缀
5. **质感优先于装饰**：用光影/层次做质感，不靠色彩堆砌

## 4. 视觉关键词

`浅色` `玻璃拟态` `瑞士排版` `留白` `平静` `低饱和` `通透`

## 5. 设计规范（Design Tokens）

### 5.1 配色（浅色为主）

| Token              | 值                      | 用途                               |
| ------------------ | ----------------------- | ---------------------------------- |
| `--bg`             | `#f5f5f7`               | 页面底色（暖灰白）                 |
| `--bg-blob-a`      | 低饱和蓝 `#dbeafe`      | 背景光斑 A（给毛玻璃提供模糊内容） |
| `--bg-blob-b`      | 低饱和紫 `#ede9fe`      | 背景光斑 B                         |
| `--surface`        | `rgba(255,255,255,0.6)` | 玻璃卡片底                         |
| `--surface-border` | `rgba(255,255,255,0.5)` | 玻璃边缘高光边框                   |
| `--text`           | `#1d1d1f`               | 主文字（近黑）                     |
| `--muted`          | `#6e6e73`               | 次要文字                           |
| `--accent`         | `#5e5ce6`               | 强调色（低饱和蓝紫，仅小面积）     |

> 关键：玻璃拟态需要背景有"可模糊的内容"，所以 `--bg` 之上要有 1–2 个大块柔和的低饱和光斑（渐变），让卡片的 `blur` 有层次可透。

### 5.2 玻璃拟态参数（质感核心）

```css
/* 玻璃卡片 */
background: rgba(255, 255, 255, 0.6);
backdrop-filter: blur(20px) saturate(1.8);
-webkit-backdrop-filter: blur(20px) saturate(1.8);
border: 1px solid rgba(255, 255, 255, 0.5); /* 玻璃边缘高光 */
box-shadow: 0 8px 32px rgba(0, 0, 0, 0.08); /* 柔和深度 */
```

### 5.3 字体（瑞士排版）

系统字体栈（无 CDN 依赖）：

```
-apple-system, BlinkMacSystemFont, "Segoe UI",
"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif
```

| 元素   | 字号   | 字重 | 字距    |
| ------ | ------ | ---- | ------- |
| 标题   | 40px   | 700  | -0.03em |
| 服务名 | 15px   | 550  | -0.01em |
| 描述   | 13.5px | 400  | 0       |
| 品牌名 | 15px   | 600  | 0       |

### 5.4 间距与尺寸

- 页面 padding：`80px 24px`，内容区 max-width `640px`
- 头部 → 卡片：`56px`
- 卡片网格：gap `12px`，列 `repeat(auto-fill, minmax(280px, 1fr))`
- 卡片 padding：`22px 24px`
- footer 距卡片：`64px`

### 5.5 圆角与阴影

- 卡片圆角 `16px`（玻璃拟态可稍大）
- 阴影：`0 8px 32px rgba(0,0,0,0.08)`

### 5.6 动效

| 元素       | 效果                                                         |
| ---------- | ------------------------------------------------------------ |
| 卡片 hover | 背景不透明度略升 + `translateY(-2px)` + 阴影加深，200ms ease |
| "打开 →"   | hover 浮现（opacity 0→1 + translateX）                       |
| 光斑       | 静态即可，不做动画                                           |

## 6. 反模式（明确不做）

- ❌ 色彩太多（Catppuccin 式的多色板）
- ❌ 纯色平涂的扁平（Sukoon 的缺质感）
- ❌ 深色为主（本次浅色为主）
- ❌ 花哨渐变/玻璃拟态过度（霓虹、彩虹）
- ❌ 大 emoji 标题、彩色图标堆砌

## 7. 页面结构

```
背景：--bg + 三个低饱和光斑（蓝、紫、粉，大块柔和渐变）
header（顶部定位区）
  ├── brand：SVG 猫 logo + "猫猫王国"
  ├── 时钟 + 秒（大号，轻字重）
  ├── 日期
  └── sub：个人门户 · 内容与服务的统一入口

section 公开区（访客可见）
  ├── 分组标题："探索"（地球图标）
  └── 卡片网格（占位卡片）
      ├── 博客（占位）
      ├── 文档（占位）
      └── 简历（占位）

section 私有区（需登录）
  ├── 分组标题："服务"（锁图标）
  └── 卡片网格（服务卡片，带在线状态点）
      ├── LiteLLM 网关
      └── 消耗统计

footer
  └── maomaokingdom.top
```

**分区规则**：

- 公开区在上、私有区在下
- 私有区标题带锁图标（🔒 语义），公开区用地球图标
- 占位卡片：`opacity 0.75` + "即将上线"字样，链接 `#`
- 服务卡片：带状态点（绿=在线 / 红=离线 / 灰=检测中）

## 9. 技术约束

- **纯 HTML + 内联 CSS**，单文件，无构建步骤
- **零 CDN 依赖**：内联 SVG、系统字体、无外部库
- `backdrop-filter` 需 `-webkit-` 前缀（Safari）
- 部署：Caddy `file_server` 静态托管（新服务器 `/opt/site/`）
